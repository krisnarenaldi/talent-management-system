# Repository Agents & Architecture Guide

This document outlines the architecture, code organization, and development guidelines for the Talent Management System repository.

## Overview
The repository is a full-stack Talent Management System featuring a Next.js frontend (`frontend/`) and backend services/integration.

## Key Directories
- `frontend/`: Next.js frontend application (App Router, TypeScript, Tailwind CSS, components, pages).
- Root configuration files, package managers, and integrations.

## Development Guidelines
- Always follow existing code styles and patterns.
- Keep components modular and maintain clean separation of concerns.
- Use TypeScript strictly.
