# Goal Description

Implement Auto-Save for "Draft Project AI" to the database so that generated drafts persist across page reloads. Also, update the "Setujui draft" (Approve) button to update the draft status in the database, and integrate approved projects into the "Generate CV" feature.

## User Review Required
> [!IMPORTANT]
> The database schema will be updated to include a new table `candidate_project`. This requires running Alembic migrations.

## Open Questions
- Limit the generation count to 1 time per candidate. For now, the plan is to only generate if no projects exist, or if the user explicitly regenerates.

## Proposed Changes

---

### Database Layer
A new model is required to store the structured projects generated by the AI, so they persist across sessions and can be used in the standard CV.

#### [NEW] backend/app/models/candidate_project.py
Create a new SQLAlchemy model `CandidateProject`:
- Fields: `id`, `candidate_id`, `project_name`, `role`, `summary`, `impact`, `tech_stack` (JSONB), `duration`, `is_draft` (Boolean, default True), `created_at`, `updated_at`.

#### [MODIFY] backend/app/models/candidate.py
Add `projects = relationship("CandidateProject", back_populates="candidate", cascade="all, delete-orphan")` to the `Candidate` model.

#### [NEW] backend/app/db/migrations/versions/...
Generate a new Alembic migration to create the `candidate_project` table.

---

### Backend API & Services

#### [MODIFY] backend/app/routers/candidates.py
1. Update `generate_candidate_project_drafts`:
   - Check if the candidate already has projects in the DB.
   - If they do, return them.
   - If they don't, call the AI service, save the results into the `candidate_project` table with `is_draft=True`, and return them.
2. Add a new endpoint `PATCH /api/v1/candidates/{id}/projects/{project_id}`:
   - This endpoint will be called when the user clicks "Setujui draft".
   - It will update the project fields (if edited) and set `is_draft=False` (or toggle it).

#### [MODIFY] backend/app/schemas/candidate.py
Add Pydantic schemas for `CandidateProject` (Create, Update, Response).

#### [MODIFY] backend/app/services/cv_generator_service.py
Update the CV generation context to include `candidate.projects` where `is_draft=False` so that the CV template can access the approved projects.

#### [MODIFY] backend/app/templates/cv/altek_standard.html
Update the "Working Experience" section to iterate through the approved projects (if any) and display them in the "Project" row, instead of hardcoding `-`.

---

### Frontend

#### [MODIFY] frontend/src/app/(dashboard)/candidates/[id]/page.tsx
1. Fetch existing projects for the candidate on page load.
2. Update the `generateDraftMutation` to reflect that it now fetches or generates and saves to DB.
3. Update the `updateDraftProject` function so that when a user edits a text field or clicks "Setujui draft", it triggers an API call (`PATCH`) to save the changes to the database.
